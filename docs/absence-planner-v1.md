# Abwesenheitsplaner V1

## Ziel
Mitarbeiter können Abwesenheit beantragen. Admins können sie genehmigen oder ablehnen. Genehmigte Abwesenheiten verhindern, dass Mitarbeiter in diesem Zeitraum eingeplant werden.

## Abwesenheitstypen V1
- Urlaub
- Krank
- Nicht verfügbar

## Status
- Offen
- Genehmigt
- Abgelehnt
